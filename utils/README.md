# Utilities for YouTube Automation System

This directory contains helper modules for the automation pipeline.

## Modules

- **fetch_trends.py**: Google Trends RSS parser
- **openai_generator.py**: OpenAI API for script generation
- **elevenlabs_tts.py**: ElevenLabs TTS for voice generation
- **ffmpeg_render.py**: FFmpeg for video rendering
- **youtube_api.py**: YouTube Data API for upload and analytics
